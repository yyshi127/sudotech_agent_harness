# 有成分模块快捷入口方案

[English](youcheng-quick-actions-plan.md) | 中文

当前范围仅财务。下文报销及 R 阶段条目是暂缓设计备忘，不是开发任务；财务验收通过也不自动启动，须用户另行明确要求。财务和报销的业务上下文、凭据、数据访问、任务及确认必须隔离。

## 定位与顺序

快捷入口按[开发计划](youcheng-natural-language-development-plan.zh.md)分别服务财务和报销模块。先开发财务入口，财务整体验收通过前不开发新报销入口；已有报销样例保留，不扩展。当前仅做方案。

按钮只预填可编辑提示词，不直接调用 API。发送后使用当前模块自己的工具、校验、预览、确认、任务记录和回查。按钮或修改后的提示词不能隐式改变模块身份。

## 最小设计

每个入口保存标识、名称、提示词、所属模块和所需动作。支持状态由后端提供，模块／客户身份由后端强制检查。不需要通用业务分发器或动态按钮设计器。

| 所属模块 | 入口 | 验收依赖 |
|---|---|---|
| 财务 | 查凭证／余额 | F1；账套、期间及完整性准确 |
| 财务 | 生成凭证建议及创建 | F2；本地准备与确认后的外部写入分开 |
| 财务 | 查日记账／往来 | F1／F3；必要资料及安全维护动作 |
| 财务 | 查看或恢复财务任务 | F2／F3；独立财务任务查询及未知结果回查 |
| 报销，暂缓 | 查单／创建或修改草稿 | R0／R1／R2；F4 验收后才启动 |
| 报销，暂缓 | 查报销任务／扫描发票目录 | R1／R3；不使用财务记录、权限或任务 |

模块开发期间可测试入口，但不能替代模块整体验收。未支持的过账、审批、付款或其他动作保持不可用。缺少权限或能力时说明原因，不能转调用另一模块。

## 隔离验收

财务会话不加载报销工具、规则、任务列表或业务数据；报销会话不加载财务对应内容。切换模块建立新上下文，不携带待确认状态或材料授权。提示词改为另一模块动作时停止并要求明确切换上下文，不跨模块执行。

仅共用展示和输入组件；查询结果、任务进度、确认及设置按模块隔离。同一个客户名称不授予另一业务的访问权。

财务完成且 F4 验收通过后，才增加报销入口。本方案不启动开发或业务写入。
