# @deepseek-ai/dsh-client-ui-xiaojing-finance-clients

[English](README.md) | 中文

小兢会计 Finance 本地客户档案与会话上下文选择的可移除 Client 展示插件。该包只在 `DSH_CLIENT_BUILD_PROFILE=xiaojing` 时编译；从 Web 组合中删除对应行即可移除全部 Finance 客户界面，不会修改 Host 服务、其他预设或官方 Harness UI。

## 设置页

插件以顺序 `22` 注册 id 为 `finance-clients` 的 `settings.section`，位于“Agent 预设”之后、“频道”之前。页面展示启用和归档的纳税主体，可创建、编辑完整档案，并在明确确认后归档启用客户。每次写操作都使用 Host 返回的目录 revision，因此并发修改会显示冲突，而不是静默覆盖数据。

页面只通过 loopback Remote 读取完整详情。浏览器不会另外持久化客户档案、凭据或外部系统秘密。

## 会话上下文

插件只为 Finance 空白会话填充通用 `conversation.hero.context` slot。Finance 预设旁显示紧凑的“咨询／客户”选择器，默认是“咨询”；选择“客户”后才显示客户下拉框，下拉框底部可直接新增客户。客户可在第一轮之前反复更改；绑定后，会话标题区显示只读客户名称。咨询会话开始工作后不能被静默转换为客户会话。会计年月、季度或年度不是会话属性，由具体财务 Skill 在执行任务时从用户指令读取或询问。

输入区阻塞采用带 owner 的独立状态，因此 Finance 校验不会删除模型、上传、Goal、Plan 或其他功能设置的阻塞原因。连接重置时，Client 会清除对 Host 内存暂存状态的假设，并重新读取权威会话状态。

## 统一上传

该插件监听现有上传按钮使用的产品中立本地文件准备事件，并接管已经就绪的 Finance 会话。它延迟执行一次普通本地上传，再要求 Host 在当前会话登记该文件。客户会话会把文件复制到所选客户的原始资料，并返回指向该副本的替换元数据；通用咨询会话把文件保留在受保护上传目录，通过会话级授权记录开放读取，不创建客户副本。客户会话中的受支持图片继续保留在原生视觉草稿中，同时把同一份内容导入客户档案目录。

本地会话摘要中明确为非 Finance 的会话会在调用 Finance Remote 或上传前返回未接管，因此上传插件沿用原有路径，不会增加延迟或重复上传；摘要中尚无记录的会话会先由 Host 判定归属。受控登记或导入失败时，文档不会附加，新加入的图片会从草稿撤回；浏览器会显示失败原因，并保持输入光标和附件状态一致。

## 财务工作区类别

插件通过通用 `WorkspaceCategoryRegistry` 注册“财务工作区”，并把普通类别显示为“普通工作区”。财务类别把咨询 Workspace 放在“咨询”分类下，把客户 Workspace 放在“客户”分类下；归档客户继续显示历史会话，但不再提供新建会话按钮。两个分类中的 Workspace 都使用同一套行菜单重命名和移除操作。移除只会从财务列表隐藏 Workspace，目录、注册、客户档案和会话历史都保留；再次添加同一目录即可恢复，最后一个仍在列表中的咨询 Workspace 不能移除。

在普通空白会话中选择 Finance 预设，会自动打开财务“咨询” Workspace 中的空白会话；在 Finance 空白会话中切换到 Standard、Plan、Goal 或其他非 Finance 预设，会返回先前的普通工作区。会话顶部的 Workspace 选择器也按预设过滤：Finance 只列出财务 Workspace，其他预设只列出普通 Workspace。选择客户时，系统先进入该客户 Workspace，再暂存客户上下文。通用侧边栏只负责渲染和搜索，产品插件负责类别成员与路由；移除插件后，普通工作区 UI 不需要保留任何 Finance 条件。

## 模型体验

本包通过 Host 所属的 `financeClients.stage` 选择间接影响模型；Finance 领域插件在第一次请求前记录并渲染该上下文。

#### KV Cache 影响

本包没有直接影响。模型可见的通用或客户上下文及其缓存影响由 Host 包负责。

## 已知限制与暂缓事项

- 设置页只支持手工维护。
- 归档客户只读保留，用于历史查阅。
- 控件和专属工作区类别只出现在随产品提供的 Finance 预设中；用户自建预设和其他系统预设不会显示。
- 普通 Web 页面只有在 loopback 下才能使用完整功能；局域网浏览器不能读取客户详情或修改暂存上下文。
- Client 只负责启动受控导入，不判断后续作业文件属于草稿、正式成果还是归档；该判断由 Finance Host 上下文和 `finance_files` 工具负责。
