# @deepseek-ai/dsh-client-ui-xiaojing-finance-clients

[English](README.md) | 中文

小兢会计 Finance 本地客户档案与会话上下文选择的可移除 Client 展示插件。该包只在 `DSH_CLIENT_BUILD_PROFILE=xiaojing` 时编译；从 Web 组合中删除对应行即可移除全部 Finance 客户界面，不会修改 Host 服务、其他预设或官方 Harness UI。界面将这些记录称为“账套”；持久化、Remote 标识和 Workspace 路径仍使用 Finance 客户模型。

## 帐套信息

空白会话的账套选择器按“客户简称-账套名称-ID 值”显示选项和选中标签；历史记录缺少简称时临时回退主体全称。有成账套名称与 ID 一起保存，重启后不会把已知名称替换为通用标签；历史记录缺少已保存名称时继续显示通用标签，重新选择并保存绑定后即可补齐。标签被截断时，悬停仍可查看完整内容。选择仍使用本地客户 ID，不使用显示文案。

插件在 Finance 客户 Workspace 的行操作菜单中加入“帐套信息”，顺序位于“重命名”之前；咨询和普通 Workspace 不显示该操作，设置页不提供客户管理。浮层读取所选客户的完整档案，并提交开始编辑时取得的 revision，因此并发修改会显示冲突，而不是静默覆盖数据。

编辑器把客户基本资料和财务系统配置分开。新增和修改时必须填写简称，因为紧凑菜单不适合显示过长的主体全称。客户可以暂不配置财务系统；选择有成后显示测试／生产环境、AppKey、AppSecret 和账套 ID，SDOO、用友和金蝶只保留可选占位，不显示连接字段。该表单不手工维护科目映射。页面只通过 loopback Remote 读取完整详情，并且不会收到已保存的 AppSecret；秘密留空时会保留 Host 已持有的凭据。

有成表单在宽屏下将“API 环境”和 Host 解析后的只读“API 地址”并排显示，窄屏改为上下排列。保存后会单独启动连接核验并显示进度，核验失败不会撤销已保存的档案。核验成功后，客户 Workspace 名称旁显示已核验的账套名和有成财务 Logo 左侧的 16 px 方形图标；失败时显示带安全错误说明的红点。灰点表示未核验，包括 Host 重启后的状态。悬浮及无障碍标签包含 ID 和上次核验时间；该标记不授予业务权限。咨询和普通 Workspace 不显示该标记。

帐套信息弹窗限制在视口内，表单字段独立滚动，标题和底部操作区始终可见；窄屏采用单列布局。可选的财务政策备注默认收起，展开后可编辑，保存其他字段时会保留已有内容。备注为客户 AI 上下文提供信息，不用于 API 鉴权或权限控制。

编辑器通过“验证并获取账套”取得候选列表，再由用户按名称单选；绑定 ID 取自所选账套并显示在选项中，不提供独立 ID 输入框。获取列表使用草稿凭据，不会保存它们。修改财务系统、环境、AppKey 或 AppSecret 会清空候选列表和已选 ID，旧请求的延迟响应不能恢复已失效的选择。已有绑定无需重新输入凭据即可保存；主动重新获取列表后需要重新选择。取消编辑不改变已保存的绑定。

loopback 页面上已配置有成的活跃账套行在客户名称和已核验账套名称之间显示常驻链接图标。核验成功后链接横向显示并变绿，账套名称后的成功状态点由有成方形品牌图标替代。该操作核验已保存的绑定，不打开编辑器、不重写客户目录、不展开行，也不改变当前会话。核验期间链接禁用；安全错误允许重试。Host 重启后需要再次主动核验，无需再次保存。已归档或未配置的行不提供连接操作。

连接诊断区分超时、网络故障和 HTTP 403 拒绝访问。重新核验失败会取消绿色成功标记，即使仍显示先前核验过的账套名称；重试继续使用已保存配置。

## 附件与报销配置

loopback 小兢页面的设置提供“附件存储”，编辑本机全局的私有 OSS 配置，接收只写 RAM 凭据，并区分保存与真实的上传／下载／清理测试。未保存修改会使已显示的测试结果失效。新安装只有部署默认的非秘密配置，仍需各自获授权的密钥，不假定存在产品登录或内置凭据。存储范围与传输限制由 [Finance Host](../../xiaojing/xiaojing-finance-domain/README.zh.md#private-attachments-and-reimbursement-drafts) 定义。

帐套信息编辑器仅提供财务连接设置，不加载、保存或测试报销配置。已保存的报销凭据与历史记录保留在 Host 存储中；移除此界面入口不会删除这些数据，也不会禁用既有后端能力。附件存储设置仍单独保留。

## 会话上下文

本产品注册的财务工具名称在聊天中使用专用卡片。成功调用显示 `tool/result.meta` 中持久保存的业务摘要；运行中及缺少该元数据的旧调用只显示本地化状态，不展开原始参数或供模型使用的 JSON。失败调用显示本地化状态；当结果包含一段经过筛查的简短文字时，还显示具体原因，结构化或技术性错误继续隐藏。模型仍能获得完整工具结果。该卡片只作用于小兢财务工具，不改变 Harness 通用展示。

已提交的 `finance/file-published` 事件在聊天中显示明确的文件打开按钮，历史重载后仍可显示。操作使用记录的目标路径和现有 Host 打开功能，不依赖模型编写链接，也不自动打开。非回环浏览器不能启用此操作。这是本地文件打开，不是下载托管，也不证明文件仍存在。导入、归档和导出失败不生成发布按钮。

插件只为 Finance 空白会话填充通用 `conversation.hero.context` slot。Finance 预设旁显示紧凑的“咨询／账套”选择器，默认是“咨询”；选择“账套”后才显示账套下拉框。客户可在第一轮之前反复更改；绑定后，会话标题区显示只读客户名称。咨询会话开始工作后不能被静默转换为客户会话。会计年月、季度或年度不是会话属性，由具体财务 Skill 在执行任务时从用户指令读取或询问。

输入区阻塞采用带 owner 的独立状态，因此 Finance 校验不会删除模型、上传、Goal、Plan 或其他功能设置的阻塞原因。成功暂存后会刷新上下文显示，即使侧边栏操作复用当前空白会话也是如此；暂存失败时保留先前的上下文。连接重置时，Client 会清除对 Host 内存暂存状态的假设，并重新读取权威会话状态。

## 统一上传

该插件监听现有上传按钮使用的产品中立本地文件准备事件，并接管已经就绪的 Finance 会话。它延迟执行一次普通本地上传，再要求 Host 在当前会话登记该文件。客户会话会把文件复制到所选客户的原始资料，并返回指向该副本的替换元数据；通用咨询会话把文件保留在受保护上传目录，通过会话级授权记录开放读取，不创建客户副本。客户会话中的受支持图片继续保留在原生视觉草稿中，同时把同一份内容导入客户档案目录。

本地会话摘要中明确为非 Finance 的会话会在调用 Finance Remote 或上传前返回未接管，因此上传插件沿用原有路径，不会增加延迟或重复上传；摘要中尚无记录的会话会先由 Host 判定归属。受控登记或导入失败时，文档不会附加，新加入的图片会从草稿撤回；浏览器会显示失败原因，并保持输入光标和附件状态一致。

## 财务工作区类别

插件通过通用 `WorkspaceCategoryRegistry` 注册财务 Workspace 提供方，并把两个顶层类别显示为“办公搭子”和“财务助手”。财务类别把客户 Workspace 放在带浅绿色账套图标的“账套”分类下，把咨询 Workspace 放在带浅绿色讨论图标的“咨询”分类下；归档客户继续显示历史会话，但不再提供新建会话按钮。客户行菜单依次显示“帐套信息”“重命名”“移除工作区”，咨询行只保留通用的重命名和移除操作。移除只会从财务列表隐藏 Workspace，目录、注册、客户档案和会话历史都保留；再次添加同一目录即可恢复，最后一个仍在列表中的咨询 Workspace 不能移除。

在普通空白会话中选择 Finance 预设，会自动打开财务“咨询” Workspace 中的空白会话；在 Finance 空白会话中切换到 Standard、Plan、Goal 或其他非 Finance 预设，会返回先前的普通工作区。会话顶部的 Workspace 选择器也按预设过滤：Finance 只列出财务 Workspace，其他预设只列出普通 Workspace。选择客户时，系统先进入该客户 Workspace，再暂存客户上下文。通用侧边栏只负责渲染和搜索，产品插件负责类别成员与路由；移除插件后，普通工作区 UI 不需要保留任何 Finance 条件。

工作区激活会通过 `remote.agentPresets` 选择 Finance 预设；客户端界面在提供财务导航前注入该 Remote。

财务激活和返回普通工作区的导航，仅在没有后续导航或插件卸载使其失效时才打开目标。过期请求可能完成空白会话的创建和准备，但不能覆盖用户之后做出的选择。

## 模型体验

本包通过 Host 所属的 `financeClients.stage` 选择间接影响模型；Finance 领域插件在第一次请求前记录并渲染该上下文。

#### KV Cache 影响

本包没有直接影响。模型可见的通用或客户上下文及其缓存影响由 Host 包负责。

## 已知限制与暂缓事项

- 新建客户时录入必填基本资料；财务系统配置通过新客户的“帐套信息”操作完成。
- SDOO、用友和金蝶只是系统选择占位；只有有成显示连接字段。
- 归档客户只读保留，用于历史查阅。
- 控件和专属工作区类别只出现在随产品提供的 Finance 预设中；用户自建预设和其他系统预设不会显示。
- 普通 Web 页面只有在 loopback 下才能使用完整功能；局域网浏览器不能读取客户详情或修改暂存上下文。
- Client 只负责启动受控导入，不判断后续作业文件属于草稿、正式成果还是归档；该判断由 Finance Host 上下文和 `finance_files` 工具负责。
