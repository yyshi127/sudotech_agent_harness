# @deepseek-ai/dsh-client-ui-xiaojing-browser-control

[English](README.md) | 中文

小兢会计本地浏览器偏好的浏览器端展示插件。它注册名为“浏览器控制”的独立 `settings.section`，不会向“通用设置”添加条目，也不拥有浏览器进程或持久数据。

插件仅在 `xiaojing` Client 构建 profile 且来源为回环地址时启用。它绑定 Host 所有的 `xiaojing-browser-control` 设置命名空间，提供 Edge 和 Chrome 选择，并说明浏览器采用可见方式启动、最小化后继续执行协议级 DOM 操作，而且两款浏览器各自使用独立的专用登录 profile。Host 插件会等待已经接受的浏览器操作结束，再应用保存的选择。

从产品组合移除本包即可删除设置入口，不需要修改 Harness UI 代码；同时移除 Host 浏览器操控插件即可删除工具和设置命名空间。专用 profile 文件会保留在用户数据中，除非用户明确删除。

## 模型体验

无。这个纯浏览器设置插件只展示 Host 所有的浏览器偏好，不注册任何模型可见内容。

#### KV Cache 影响

无直接影响；打开页面或选择浏览器不会改变模型请求。

## 已知限制与后续工作

- 只有本机已安装 Google Chrome 时才能选择 Chrome；启动失败后，Host 不会改用另一款浏览器。
- 已保存的浏览器切换会等待已经接受的浏览器操作结束，并从下一次操作开始生效。
- 浏览器最小化后仍可继续执行协议级 DOM 自动化，但浏览器原生对话框和系统对话框仍需使用独立的电脑操控能力。
