# @deepseek-ai/dsh-xiaojing-finance-domain

[English](README.md) | 中文

小兢会计 Finance 模式的本地纳税主体档案与会话客户上下文 Host 能力。该 Cordis 插件负责存储、基于 revision 的安全修改、首轮前选择、持久化会话绑定、浏览器 Remote 和模型可见的 Finance 上下文。它不修改 Agent Loop，并且只由小兢会计产品组合加载。

## 客户档案

一条记录对应一个独立纳税主体。必填字段是主体全称、纳税人类型、注册地区和会计准则；可选字段包括简称、统一社会信用代码、行业、财务政策备注、科目映射，以及不含秘密的有成或 SDOO 租户、公司和账套标识。系统不接受密码或 Token。

客户目录保存在 `$DSH_HOME/finance/clients-v1.json`，schema 版本为 `1`。每次修改都必须提交文件级 `expectedRevision`；编辑窗口持有旧 revision 时会被拒绝，不会覆盖另一个窗口的修改。写入使用文件锁和原子替换。文件损坏时插件拒绝启动，并保留原文件不变。客户只能归档，不能物理删除；归档客户仍可供历史会话读取，但不能创建新会话。

## Finance 专属工作区

Finance 拥有与普通 Harness 工作区分离的用户可见工作区根目录。桌面产品将其设置为 `文档/小兢会计工作区/Finance工作区`，其他部署也可提供不同的绝对 `workspaceRoot`。根目录包含一个固定显示为“咨询”的 Workspace，并为客户目录中的每条记录生成一个 `clients/<client-id>` Workspace。目录使用稳定客户 ID，而不是可编辑的显示名称，因此客户改名不会改变路径。

创建客户时，系统先生成 `00-客户档案`、`01-财务政策`、`02-原始资料`、`03-会话作业`、`04-成果输出` 和 `05-归档`，并向 Harness Workspace 注册客户根目录，然后才提交客户目录记录。修改失败时会撤销新注册和新目录。启动时若发现上次创建中断留下的孤立 Workspace 注册，只移除注册并保留目录和文件，以便人工恢复。归档客户继续保留 Workspace 和历史会话，但不能新建会话。

Workspace 显示名称与财务列表成员关系独立保存在 `$DSH_HOME/finance/workspace-presentation-v1.json`，使用 schema 版本 `1`、revision、进程安全文件锁和原子替换。重命名会同时修改 Harness 注册标题和展示记录，不改变目录。移除咨询或客户 Workspace 只会从财务列表隐藏，仍保留注册、目录、客户档案和会话；通过添加操作再次选择同一目录即可恢复。列表中必须至少保留一个咨询 Workspace。

客户会话把选定客户根目录作为不可变 `cwd`，每个会话在 `03-会话作业` 下使用独立子目录。每个子目录都会原子写入 `会话信息.json`，记录会话 ID、客户 ID、客户档案版本和显示名称；完整聊天记录仍以 Harness 会话存储为准，该目录只保存作业文件和身份清单。会计期间不是客户目录或会话的固定属性；报税、查账、做账等 Skill 可按当前任务在原始资料、成果或归档目录下创建期间子目录。咨询必须运行在固定咨询目录。Host 会拒绝在客户目录中运行咨询，也会拒绝在一个客户的工作区中绑定另一个客户。

## 受控文件生命周期

用户继续使用同一个上传入口。客户 Finance 会话完成本地上传后，系统把文件复制到 `02-原始资料`，保留上传暂存文件；受支持图片还会继续作为原生视觉附件。通用 Finance 咨询会把文件保留在受保护的本地上传目录，并落盘一条会话级 `finance/consultation-file-imported` 事件，记录真实路径、显示名称、大小和 SHA-256。非 Finance 会话保持普通上传行为。

每个客户会话只在自身的 `03-会话作业/<session-id>` 目录中进行临时工作。Finance 预设增加 `finance_files` 工具：用户以自然语言要求最终版、导出、交付或保存正式成果时调用 `publish`，把已经存在的本会话作业文件复制到 `04-成果输出`；草稿、预览、试算和意图不明确的内容继续留在会话作业目录。只有明确归档意图才调用 `archive`，把该客户的原始资料、当前会话作业或正式成果复制到 `05-归档` 下按北京时间日期生成的子目录。两个操作都不会移动或删除源文件。

每次成功的客户文件复制都会追加到客户根目录下的 `.xiaojing-finance-files-v1.json`，其中保存 schema 版本 `1`、revision、所属客户和会话、操作、绝对目标路径、字节数、SHA-256 摘要及可选源记录 ID。对应的 `finance/file-imported`、`finance/file-published` 或 `finance/file-archived` 事件会在操作返回前落盘；通用咨询登记则落盘 `finance/consultation-file-imported`，不会写客户索引。这些事件使模型可见来源授权可以从会话日志重建。目标文件和客户索引采用原子写入；源路径无效、跨客户或索引损坏时会失败，并保留源文件和损坏索引不变。

## 会话上下文

空白 Finance 会话默认为通用财务咨询。浏览器可在第一轮之前把客户暂存在 Host 内存中，暂存内容不写入日志，并可反复更改。第一次模型请求会先追加并落盘一条 `finance/client-bound` 事件，再把上下文交给模型。该事件只包含不可变客户快照和客户档案版本。

以后修改客户档案只影响未来会话。历史会话始终从自身日志恢复原快照。`financeClient` 会话投影只向浏览器公开显示名称和绑定状态；税号、政策备注、科目映射和外部系统标识保留在 Host。客户专属写操作统一调用 `requireBoundClient()`，通用咨询会被直接拒绝；只读 Finance 服务可以通过 `currentClientBinding()` 取得同一份不可变快照，也可以在没有客户上下文时继续运行。

Finance 预设消费端以 `@deepseek-ai/dsh-xiaojing-finance-domain/context` 独立导出。删除该预设配置行即可移除模型上下文；Web 组合中的 Host 客户档案服务仍可独立插拔。

## Remote 与隐私

`financeClients` Remote 提供客户档案操作、Workspace 列出／添加／重命名／移除／恢复操作，以及 `stage` 和 `sessionContext`。完整详情读取、全部写操作和暂存选择仅允许 loopback 连接。列表、Workspace 标识与会话上下文使用脱敏返回类型。Client 不会收到 Workspace 文件路径、密码、Token 或其他会话的完整不可变快照。

## 模型体验

### Finance 客户上下文

#### 模型可见内容

通用 Finance 会话会明确声明当前未绑定客户，禁止推测客户事实。客户会话只获得 `finance/client-bound` 中记录的不可变快照，并明确要求按当前任务确定期间。Standard 等其他预设不会获得 Finance 客户上下文。

#### Token 影响

通用会话增加一条固定的短指令。绑定会话增加随客户字段变化的内容；未选择的客户档案不会进入请求。

#### KV Cache 影响

通用上下文在通用 Finance 会话之间保持稳定。客户上下文随客户快照变化，因此只有模型可见值完全相同时才能共享提示词缓存。

## 已知限制与暂缓事项

- V1 只支持手工维护，不提供 Excel 导入、联系人、合同、销售、收费或 CRM 流程。
- 财务政策文件尚未接入客户档案；V1 只保存结构化文字备注。
- 外部系统引用只是标识，本包不连接有成或 SDOO。
- 通用会话开始第一轮后不能中途补绑客户，用户必须新建 Finance 会话。
- 受控上传、发布和归档操作会执行上述目录规则，但 Full Access 下的 shell 与文件系统工具仍可在操作系统授予的权限范围内直接写入。
