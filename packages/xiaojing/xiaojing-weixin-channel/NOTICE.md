# Tencent openclaw-weixin attribution

The iLink protocol adapter in this package is adapted from `Tencent/openclaw-weixin` at commit `cef0bfc390393f716903e16d50408118047f87e0`.

Local modifications retain only the protocol and encrypted image/document transfer needed by the Xiaojing Cordis plugin, restrict requests to Tencent's official iLink and CDN hosts, validate external JSON, store credentials and state in Harness-owned services, and omit OpenClaw integration, audio, and video handling.

Tencent is pleased to support the open source community by making openclaw-weixin available.
