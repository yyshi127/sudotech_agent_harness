# @deepseek-ai/dsh-xiaojing-finance-evidence

[English](README.md) | 中文

## 概述

小兢 Finance 用于按日期从中国大陆官方来源研究财税规则的 Host 能力。Host 插件负责来源准入、受限页面抓取、依据解析和结构化本地缓存；独立的 Finance 预设消费端注册 `finance_evidence`，Standard 等其他预设不会获得该工具。两个入口均不修改 Agent Loop。

## 检索与依据语义

服务只使用 Harness 现有 Web 搜索能力发现候选 URL，再由私有 HTTP 抓取器访问固定官方清单中的 HTTPS 页面，包括国家法律法规数据库、中国政府网、国家税务总局政策法规库及官网、财政部网站和省级税务机关网站。搜索标题和摘要始终只是发现线索，只有取得官方页面正文后才能成为依据。

取得正文后，服务生成可归属的元数据、受限摘录、响应 SHA-256、抓取时间、法律效力分类、相对于指定日期的状态、条件适用性及明确限制。权威层级从法定文本、约束性规则、主管机关指引到官方解释材料；L4 专业组织或国际材料不在本次“仅官方来源”清单内。权威层级不能代替法律效力、现行状态或对用户事实的适用性判断。

`verified` 表示至少一份已抓取官方页面同时具有可识别的法律效力和现行状态；`partial` 表示找到了官方材料，但无法确认全部必要属性；`pending` 表示没有取得可引用的官方正文；`out-of-scope` 表示请求属于香港、澳门、台湾或境外司法辖区。这些状态只描述依据可用程度，不构成法律意见，也不表示规则必然适用于某个客户。

请求可以指定评估日期和中国大陆地区；日期默认使用北京时间当日。客户会话会从不可变客户快照的注册地址取得默认地区，但该值只作为检索前提，不能证明适用性。苏州等中国大陆城市仍属于支持范围，并会检索国家级及适用的省级来源。通用 Finance 会话在未指定地区时只检索国家层级来源。官方依据一旦达到 `verified`，后续客户适用性仍未知只能作为独立限制，不能把依据状态重新降级。

## 持久化、隐私与失败行为

受限缓存保存到 `$DSH_HOME/finance/evidence-cache-v1.json`，使用 schema 版本 `1`、文件锁和原子替换。它只保存解析后的元数据、短官方正文摘录、摘要值和抓取状态，不保存 API Key、客户档案、搜索摘要或批量官方语料。缓存损坏会阻止插件初始化，并保留原文件不变。

页面公开可访问不等于取得再分发授权，因此每条依据都保留 `terms-review-pending`。服务不会声称已经完成 robots、网站条款、语料完整性或复用权利审查。抓取失败、跳转被拒、页面不可用或状态信息不完整时，只返回发现线索或部分核验结果，不编造引用；底层抓取异常也不会暴露给模型。

搜索、抓取、摘录、缓存、超时、正文大小、URL 长度和跳转上限均由部署配置控制。直接抓取器只供本包内部使用，不会为 Agent 开启通用 Web 抓取。完整生成配置见[配置目录](../../../docs/config-catalog.zh.md)。

## 模型体验

### 官方依据工具

#### 模型看到什么

Finance 获得 `finance_evidence(query, as_of_date?, locality?)`。结果作为普通 `tool/result` 持久化，并渲染为中文依据报告，包含官方直达链接、权威来源、状态、法律效力、日期、摘录、前提和限制。随产品提供的 Finance Skill 要求在作出确定性的时效性规则结论前调用本工具，并对部分核验或待核验命题明确写出“待核验”。

#### Token 影响

只有当前请求的研究结果进入对应会话。受限摘录控制可变工具结果长度，本包不会把常驻本地语料库注入每次提示词。

#### KV Cache 影响

工具输出随问题、日期、地区、当前官方页面及缓存状态变化，因此位于稳定 Finance 系统提示词之后，不改变固定提示词前缀。

## 已知限制与后续工作

- 删除 `xiaojing-finance-evidence` Host 配置行和 Finance 预设中的 `finance-evidence` 消费端配置行即可移除该能力；客户域、受控文件、Standard 模式和官方 Harness profile 相互独立。
- 本包不是完整财税法规库，不会对每一项官方目录做全量核对，也不执行后台更新监测。
- 本包不能替代申报、争议、交易等高风险事项的专业复核。
