# @deepseek-ai/dsh-xiaojing-desktop-companion

[English](README.md) | 中文

小兢会计 Windows 桌面宠物的 Host 侧任务状态聚合插件。这个 Cordis 插件观察 Harness 会话、审批以及脱敏后的微信状态事件，并向 Electron 桌面端发布一份不含任务内容的全局快照。它不修改 Agent Loop、任务执行、模型提示词或用户会话。

## 组合与状态

该插件仅由小兢会计产品组合加载。它跟踪开放轮次、未完成工具、未解决审批、最近终态和脱敏后的微信在线标记。全局状态优先级依次为等待确认、失败、执行、思考、成功和待机。完成轮次保留成功状态 2.5 秒，失败、阻塞、达到最大 token 和中断轮次保留失败状态 5 秒。多个活动轮次只汇总为数量。

导出的 `CompanionSnapshot` 只包含 `state`、`activeTaskCount`、`approvalCount`、`weixinOnline` 和 `revision`。它不包含会话标题、用户指令、文件名、工具参数、模型回复、API Key 或微信凭据。跟踪器只按会话保留生命周期计数和时间戳，并在会话被释放时删除对应记录。

## 桌面传输

Host 在 `/xiaojing-desktop-companion` 下提供仅限 loopback 的 JSON 快照端点和 Server-Sent Events 推送流。Electron 主进程消费该推送流，并独立拥有所有原生窗口、托盘菜单、持久化和动画。普通浏览器客户端不会通过本插件获得原生桌面控制通道。

推送流先发送初始快照，再发送后续 revision，并使用不含内容的心跳注释维持连接。客户端断开时会移除流监听器。Host 为最近的成功或失败状态只安排一个到期定时器，使快照无需轮询即可恢复到下一个适用状态。

## 模型体验

无，因为该插件只观察已经写入日志的生命周期事件，不贡献提示词、模型输入、工具 schema 或会话事件。

#### KV Cache 影响

没有直接影响；桌面宠物状态和微信连接状态都不会改变模型请求。

## 已知限制与延期工作

- Host 报告语义任务生命周期状态，不报告进度百分比或任务内容。
- 桌面显示、动画、拖动和系统托盘生命周期属于 Windows Electron 层，普通网页中不可用。
- 进程重启会清除短暂的成功和失败计时；活动状态由新的生命周期事件重建，不重播历史动画。
