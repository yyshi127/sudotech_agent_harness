# @deepseek-ai/dsh-xiaojing-finance-calculations

[English](README.md) | 中文

## 概述

小兢 Finance 的版本化确定性财税试算能力。Host 服务负责纯十进制计算和客户上下文适配，独立的 Finance 预设消费端注册 `finance_calculation`；Standard 等其他预设不会获得该工具，两个入口均不修改 Agent Loop。

## 支持的规则包

规则集 `cn-mainland-2026-v1` 支持 2026-01-01 至 2027-12-31 的依据日期，首版限定为四类试算：

- 一般纳税人与小规模纳税人增值税试算；
- 以实际缴纳的增值税、消费税为基础的城市维护建设税、教育费附加和地方教育附加试算；
- 一般企业及符合条件的小型微利企业所得税预缴试算；
- 居民个人工资薪金累计预扣个人所得税试算。

内置依据均指向现行官方法律或政策页面。服务不会假定临时优惠自动延续；依据日期超出规则包期间时直接拒绝试算。它也不会替用户选择更有利的纳税人类型或优惠资格，而是要求补齐重要适用事实。

金额以十进制字符串跨越工具接口，并使用 `decimal.js` 计算。每项税费结果采用 `ROUND_HALF_UP` 保留两位小数。结果包含规范化输入、输入来自请求/客户/规则的标识、逐步公式、输出、规则版本、官方依据、前提、限制和“仅供试算”声明。

## 客户上下文与失败行为

客户会话从不可变会话快照取得纳税人类型；请求与快照冲突时拒绝计算。未绑定客户的 Finance 咨询在增值税试算时必须明确纳税人类型。本包不读取随时变化的客户档案，也不另建试算账本；普通 `tool/call` 与 `tool/result` 事件足以从会话日志重建每次模型可见试算。

缺少字段或字段冲突时返回 `needs-input`，且不输出部分数值；无效日期和金额会被拒绝；超出规则期间时返回 `unsupported`，并要求先通过 `finance_evidence` 核验目标日期的规则。

## 模型体验

### 确定性财税试算

#### 模型看到什么

Finance 获得 `finance_calculation`。工具说明列出各试算类型所需字段；结果渲染为中文报告，包括状态、带来源的输入、公式、舍入结果、官方依据、前提、限制，以及“不是申报、缴款、审计或过账结果”的明确声明。

#### Token 影响

只有当前请求的结构化试算进入对应会话；本包不会把税率表或规则语料注入每次提示词。

#### KV Cache 影响

固定 Finance 提示词和工具 schema 保持稳定，请求相关数值与计算轨迹只出现在该前缀之后的工具调用与结果中。

## 已知限制与后续工作

- 首版明确不处理混合税率、简易计税、特殊行业、多数税收优惠、企业所得税汇算清缴、非工资薪金个税、消费税本身及除输入附加税率外的地方规则。
- 本包只执行试算，不生成或提交申报表，不过账、不付款，也不修改外部系统。
- 删除 `xiaojing-finance-calculations` Host 配置行和 Finance 预设中的 `finance-calculations` 消费端配置行即可移除该能力，不影响客户档案、文档、Standard 模式或官方 Harness profile。
