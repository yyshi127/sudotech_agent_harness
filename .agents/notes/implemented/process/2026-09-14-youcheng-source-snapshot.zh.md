# Agent Note: 有成文档来源产物

Status: implemented

[English](2026-09-14-youcheng-source-snapshot.md) | 中文

## 问题

供应商的中文 API 提取文件占用了英文文档路径，却没有双语配对。生成内容的硬换行也违反了项目维护文档的规则。编辑或翻译提取文件会混淆哪些表述来自供应商。

## 决定

[镜像参考页](../../../../docs/integrations/youcheng-openapi-replica.zh.md)是项目维护的双语页面，链接结构化 JSON 和 `.source.txt` 提取文件。现有提取文件迁移时保持字节不变。镜像脚本写入来源产物，不覆盖维护页面。文档检查保持原有范围和规则。

## 考虑过的替代方案

**翻译或重新排版生成的提取文件。** 这会把编辑改动与抓取的供应商示例混在一起，每次重新生成都需要审阅整个镜像。

**将镜像排除在文档检查之外。** 单文件豁免会在维护文档树中留下未配对的参考文档。简短的双语参考页能区分编辑责任与供应商数据，无需放宽检查。

## 影响

供应商原文仍可搜索和下载，但纯文本产物没有渲染后的 Markdown 导航。通过哈希比较核验迁移完整性；受控镜像运行必须保留维护页面并输出两类来源产物。任何一种产物都不能证明当前接口可用或产品通过验收。
