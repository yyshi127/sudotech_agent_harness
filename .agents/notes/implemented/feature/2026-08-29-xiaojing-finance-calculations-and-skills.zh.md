# Agent Note: 小兢 Finance 确定性试算与首批流程 Skills

Status: implemented

[English](2026-08-29-xiaojing-finance-calculations-and-skills.md) | 中文

## 问题

Finance 模式已经可以获取官方来源并标准化文档，但税额计算仍依赖模型算术，流程质量也依赖一段没有固定步骤的提示词。这可能造成事实缺失、税率过期、舍入口径不透明，以及把试算误报成申报结果。产品还需要可复用的专业流程，但本阶段不能增加外部过账、申报、审批或付款行为。

首个试算版本必须足够窄，才能被审计。它不能推断优惠资格、把搜索结果当成规则、修改客户档案、增加第二套账本或改变 Standard 模式。流程指导必须能够随 Finance 预设移除，并且只编排已有能力，不能复制文档、依据或文件逻辑。

## 决策

`@deepseek-ai/dsh-xiaojing-finance-calculations` 提供完整 Cordis 能力，包括 Host 服务、Finance 专属 `finance_calculation` 消费端和包自有 invariant companion，不修改 `agent-loop`。服务执行纯十进制运算；工具通过普通会话工具事件保留请求和完整结果，因此本包不拥有独立持久化数据。

不可变规则包 `cn-mainland-2026-v1` 支持 2026-01-01 至 2027-12-31，包含单一税率的一般纳税人增值税、小规模纳税人增值税、增值税附加税费、企业所得税预缴和居民个人工资薪金累计预扣等受限示例。金额输入使用十进制字符串，优惠资格使用显式布尔选择。输出包含标准化输入、代入数值的公式、精确结果、固定四舍五入、前提、限制、官方链接和强制试算声明。事实缺失时返回 `needs-input`，日期不在范围时返回 `unsupported`，两种结果都不会包含猜测金额。

绑定 Finance 客户时，试算器通过不可变会话绑定取得纳税人类型和注册地区。请求与客户纳税人类型冲突时直接拒绝；咨询会话必须显式提供纳税人类型。注册地区只作为上下文披露，不能自动转换成城市维护建设税税率。

产品自有 Finance skill 根目录现在包含五个流程 skill：国内官方财税依据研究、发票审核、凭证草拟、财务数据分析和报销审核。已有文档读取 skill 是支撑能力，不计作第六个业务流程。各流程按需编排 `finance_document`、`finance_evidence`、`finance_calculation` 和 `finance_files`，生成可复核的事实、计算、草稿、风险与证据缺口，但不会把任何外部业务动作报告为已完成。

小兢产品清单拥有包和 skill 清单。产品检查会比较 Finance 与 Standard 预设，只允许已声明的 Finance 消费端，验证每个 skill 路径及元数据头，并要求试算 Host 只在小兢 profile 加载。删除 Host 配置行和预设消费端即可移除试算；删除 skill 文件即可移除流程。官方 Harness profile 和 Standard 模式保持不变。

## 备选方案

- **让模型根据取得的规则自行计算。** 拒绝，因为算术、舍入、缺失输入和规则选择无法做到确定性和独立复核。
- **建设通用税务计算引擎。** 拒绝，因为首版没有足够的已核验规则覆盖、资格数据或申报集成，不能安全支持任意税额结果。
- **保存独立试算账本。** 拒绝，因为工具调用和结果已经保留全部模型可见输入输出；新增存储只会增加对账和迁移工作。
- **根据客户字段自动推断优惠和地区税率。** 拒绝，因为客户分类和注册地址不能证明全部期间性资格条件或税率档位。
- **把五个流程写成代码。** 拒绝，因为它们组织判断和工具顺序，并不拥有新的确定性服务；skill 是更小且可移除的单元。

## 验证

试算器测试覆盖绑定与未绑定纳税人类型、一般与小规模增值税、门槛处理、附加税费、两类企业所得税处理、工资薪金预扣税率表、缺失输入、客户冲突和超范围日期。工具测试固定可读审计报告与缺失输入输出。无 Key 组装快照会挂载实际小兢 Web 与 Finance 预设，使用绑定客户执行 `finance_calculation`，并记录工具 schema 和完整试算结果。

预设组合测试证明 Finance 保留 Standard 工具集，同时增加四个 Finance 工具，发现五个业务流程 skill 与文档读取 skill，并加载实际内容。产品层检查验证包发现、profile 隔离、兼容适配器、精确消费端差异和完整 skill 清单。包级 typecheck 与 build 同时验证源码面和发布产物面。

## 结果

Finance 现在可以完成一组可复现试算，并按一致的专业流程工作，而不会声称已经申报、过账、审批或付款。结果可审计、可移除，但范围有意保持有限。混合增值税税率、特殊计税方法、多数优惠、年度汇算、非工资薪金个税、地方减免、申报表、有成、SDOO 和合规判断仍不属于本版本，需要后续能力包或已核验依据支持。
