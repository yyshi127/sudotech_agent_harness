# Agent Note: 小兢会计增量版本历史

Status: implemented

[English](2026-08-30-xiaojing-incremental-release-history.md) | 中文

## Problem

小兢会计“关于”页面原本只在已安装版本下显示一份累计功能清单。Finance 功能发布后，这种展示把 0.2.2 已经具备的功能重新归入 0.2.3，也让用户无法查看上一版本实际新增了什么。

## Decision

产品包维护按版本倒序排列的 `XIAOJING_RELEASE_HISTORY`。每条记录包含一个明确版本号以及该版本新增的功能。发布新版本时只在首部增加一条记录，既有记录保持不变。“关于小兢”把首项显示为当前版本，其余记录显示为版本历史。

0.2.3 记录包含 Finance 第一阶段 F1-0 至 F1-6 的增量；0.2.2 记录保留原生视觉与统一上传、微信、Edge 控制、本机用量、Visualize 和桌面小兢。产品测试要求历史首项与 Web 版本 fallback 一致，并拒绝重复版本号；Web 设置快照记录两个版本区块。

## Alternatives considered

**继续使用当前版本累计清单。** 否决，因为累计清单无法说明相对上一版本增加了什么，而且功能清单变化时会不断改写产品历史。

**根据当前插件清单自动生成历史。** 否决，因为当前组合只能说明安装了什么，不能说明功能最初在哪个版本交付；移除或替换插件还会错误改写历史版本说明。

## Consequences

用户可以在同一页面查看已安装版本的增量变化和保留的早期版本记录。每个版本需要维护明确的数据和双语文案，但这种显式维护可以防止旧功能被静默归入新版本。该历史是产品版本记录，不是当前所有插件的完整清单。
