# Agent Note: 小兢品牌两阶段 Windows 安装器

Status: implemented

[English](2026-08-25-xiaojing-branded-two-stage-installer.md) | 中文

## 问题

标准 assisted NSIS 流程将许可、安装范围、目录、文件进度和完成操作拆成多个页面。该流程不符合小兢产品展示要求，但替换页面不能改变永久安装器身份、当前用户安装范围、自定义安装目录、覆盖升级行为或用户数据排除规则。

## 决策

桌面端继续使用 electron-builder assisted NSIS 构建目标，并通过 `apps/desktop/build/installer.nsh` 定制。全窗口欢迎页集中显示小兢标识、产品名称、数豆绿色安装操作、安装许可提示和可选的行内父目录选择器。全新安装的所有目录选择都会规范为固定的 `xiaojing-agent-desktop` 子目录。已有安装沿用注册表记录的 `InstallLocation`，且不显示路径选择。

安装器固定使用当前用户模式，因此通用安装范围页会直接终止而不改变注册表归属。内部使用说明采用中性的构建资源名 `internal-use-notice.txt`，因为 electron-builder 会为每个 `license*` 或 `eula*` 资源自动生成许可页面。安装身份门禁拒绝这些保留名称和显式 NSIS 许可页。欢迎页说明安装许可，内部使用说明、完整的 DeepSeek Harness 许可和第三方声明仍保存在安装后的 `resources/legal` 目录。

安装过程继续由 NSIS 内置 InstallFiles 页面执行并提供进度。该页面在真实进度条上方显示小兢标识和产品名称，在下方显示紧凑的 `110×28` 数豆 Logo，不显示虚构的下载速度、传输字节数或剩余时间。不可见的完成回调会启动已安装应用并退出，因此安装器只有两个可见页面。

文件安装期间保持窗口关闭命令可用，并在触发时显示品牌化确认卡片。全新安装的目标目录在开始时不存在，选择“继续安装”会解除完成屏障并进入正常流程；选择“取消安装”会启动复制到临时目录的 PowerShell 清理程序，并立即以 Windows 取消码 `1602` 退出。清理程序等待安装器进程结束，要求目录名严格等于 `xiaojing-agent-desktop`，然后删除部分应用、当前用户安装器注册表项和快捷方式。目标目录在安装前已存在时禁用取消，避免清理安装器不拥有的文件。覆盖升级在替换开始前仍可从欢迎页安全退出；替换开始后，进度页确认卡片只提供“继续安装”，避免在 electron-builder 已删除旧程序文件后中断。两种路径都不访问永久用户数据目录。

`verify-desktop-identity.mjs` 在永久安装器身份之外，还固定当前用户覆盖、两阶段页面宏、数豆绿色操作、无自动生成许可页、随包法律说明、紧凑位图尺寸、公司 Logo 的纯白外圈像素、全新安装清理程序、取消退出码和升级不可取消提示。用户数据门禁拒绝自定义安装器及其清理程序中的所有 AppData 或受保护数据引用。

## 考虑过的替代方案

**使用 electron-builder 一键安装。** 该方式可以移除额外页面，但也会移除必需的自定义安装位置，因此不能满足产品安装行为。

**维护完整的自定义 NSIS 脚本。** 该方式可以完全控制布局，但会复制 electron-builder 的解包、升级、快捷方式、卸载和应用运行逻辑，维护与升级风险大于视觉收益。

**保留标准 assisted 页面，只替换页眉图片。** 该方式改动最少，但仍保留分散的页面流程，也无法实现已确认的欢迎页和进度页。

**显示模拟的网络进度信息。** 安装器是离线包，下载速度、传输字节和倒计时都不真实，因此设计只显示实际文件安装进度。

**覆盖升级取消后静默重跑缓存的旧版安装器。** 缓存不是可靠的回滚镜像，第二个安装器进程也无法保证在 electron-builder 已删除旧程序后完成恢复。因此替换开始后不再提供取消。

## 影响

自定义 include 保留 electron-builder 安装 section 和升级行为，并负责页面组合与取消策略。它依赖 electron-builder 26.15.3 使用的 Modern UI InstallFiles 控件 ID 和自定义页面钩子，因此升级 electron-builder 时必须重新编译安装器并人工检查两个页面。全新安装取消使用外部清理程序，确保只在安装器进程退出后清理。覆盖升级在替换开始后不能取消；关闭进度页会显示说明，并只提供“继续安装”。紧凑许可提示不再提供独立的点击确认页面，但完整许可和声明仍随应用安装并可访问。迁移安装位置仍需卸载后重装，普通升级继续保留原路径和受保护用户数据。

## 验证

发布验证需要编译 NSIS 安装器，运行桌面身份、取消清理程序和用户数据检查，并分别检查全新安装和覆盖升级。全新安装必须允许选择父目录并补齐固定子目录；覆盖升级必须隐藏路径选择并沿用 `InstallLocation`；两种流程都必须显示真实进度，并在完成后启动应用。取消验证必须证明清理程序等待安装器结束后才删除允许的部分安装目录，拒绝其他目录名，并且从不引用受保护用户数据。覆盖升级验证必须证明替换前可从欢迎页退出，替换开始后的进度页确认卡片不再提供取消。
