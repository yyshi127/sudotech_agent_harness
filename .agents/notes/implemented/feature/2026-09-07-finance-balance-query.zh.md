# Agent Note: 财务科目余额表证据

Status: implemented

[English](2026-09-07-finance-balance-query.md) | 中文

## Problem

实测余额接口同时返回科目行和汇总行，但 `count` 为 0。金额空白、负借方余额和不稳定的数字汇总标识，使其不能沿用凭证列表投影或常规期末净余额假设。

## Decision

Finance 专属查询复用已保存凭据和会话账套绑定校验，核验授权账套 ID，限制行数与字节数。科目编码为空的行单独作为接口汇总；十进制金额及正负号保持不变，空白金额转为 null；不输出接口生成的汇总标识。响应计数不能证明完整性，因此覆盖范围明确保持未核验。

真实接口将四位数期初金额格式化为 `1,000.00`。金额解析器先校验无分组十进制或完整的三位数字分组，再按文本去除逗号。错误分组仍报错，精度和空值处理保持不变。结果提示和工具说明禁止将发生额空白或期初期末相等解释为本期无发生，该限制同样适用于文字总结。

回答指令将缺失值标签同时用于汇总行和科目行，保留借贷术语，禁止从金额相等推断划转或添加未核验算式。免责声明不能抵消表格或结论中的矛盾断言。提示词断言保护这些指令，但生成文字尚未经过确定性校验，因此仍需真实回答检查。

可选单层级参数映射到文档中的相同起止层级。显式范围在一次授权和共同截止时间内进行有界父级遍历。有成确认仅关闭分页不能取得全部下级；读取起始层级后，以 `parentSubjectId` 查询子科目，由 `hasChild` 控制展开直至结束层级，只保留初次汇总。重复 ID／编码、错误父级、缺失声明的下级或累计超限均拒绝整次操作。这取代了已被证伪的“平铺不分页范围即可取全”假设，根范围完整性仍未核验。结果与工作簿保留选择范围及未提供金额。

跨来源差异结论需要账户映射、币种、期间、数据集合和记账状态可比。日记账标签单独保留，避免共用期初/期末表格隐含断言二者等价。未经核验的来源保持尚未对账，仅凭金额不同不能确定错误或同步原因。

## Alternatives considered

**仅修改工具指令。** 通用分析技能也会指导混合查询回答，其解释公式的要求需要明确区分引用来源金额和执行用户要求的计算。技能保留查询工具的字段含义，并要求经过核验的计算结果；组装场景加载两处来源。这仍是指令层保护，不保证生成文字遵守要求。

可选 XLSX 导出保留此投影，不推断合计或币种。独立工作表避免混合科目行和汇总行；null 使用明确的缺失标签而不是数字零。文本单元格保留小数精度，超长值报错而不是截断。发布复用受跟踪的 Finance 文件操作，并记录确切来源摘要。导出验收与财务完整性验收分开。

**推导合计与净余额。** 逐行求和会重复计算父级余额及接口汇总。空白当零或将负借方转为贷方，会断言响应尚未证实的财务含义。

**独立查询框架。** 为单个只读操作建立独立查询框架没有必要。

**任意去除逗号或转成浮点数。** 无条件去除会静默接受格式错误的金额，浮点转换可能损失精度。先验证格式，再无损规范文本。

## Consequences

查询核对标记小兢为核验主体，来源工作簿保留该标识。真实计数验收暴露将核对归于供应商接口的歧义，因此说明区分有成金额与本地计算结果。

Host 为明确指定单月一级科目的普通查询附加共用核对结果与计数，不再以模型选中分析开关作为取得程序核对的前提，不改变提供方请求。增强发生在保存配置的读取校验内，重新检查完整字节上限。子级或范围查询不提升资格，原始 null 和完整性保持不变。一级查询组装场景覆盖普通工具路径。

工具参数说明将合计核对导向分析调用。真实新会话曾选择原始查询并计数十二个来源字段，旧会话收到正确计数后仍沿用历史错误。结果指令区分八个核对借贷字段与四个仅保留来源的 Balance 字段，要求纠正冲突的历史文字。这是调用与回答指令，不是生成结果的确定性保证。

结果对每个期间八列的状态作程序计数，指令要求文字总结使用计数；真实验收曾出现表格四列一致、总结却写六列的问题。测试核对计数与逐列状态，生成文字仍需真实验收。

一级科目分析逐个借贷列对照已提供金额之和与唯一的 `本期合计`，保留空值数，区分一致、不一致、不可核对和不支持的层级。工作簿单独输出核对页。金额一致不证明科目完整或单个空白表示零，原始 null 和未核验完整性保持不变。聚焦测试覆盖合计冲突、重复合计、缺失金额及仅子级查询。

真实模型验收暴露了与 `month` 相同的冗余 `monthEnd`。工具接受等价端点，但仍在读取或发布前拒绝真正的多月范围，组装场景覆盖两条路径；避免无必要的重试，不将有歧义的范围解释为单月。

用户要求的比较采用单个明确层级与本位币请求，不对任意科目树求和。跨月按稳定科目 ID 对齐，编码、名称或父级变化时拒绝比较。整数分保持精度，缺失行或金额不补零。八个借贷列支持差额与带范围限制的返回行加总；未提供方向信息的余额字段仅保留来源值。分析工作簿携带来源报告、范围和限制。这实现有界计算，不代表独立核验了全账套完整性。

范围结果保留科目及父级 ID，拒绝重复 ID、缺失范围内父级、矛盾的子级标志及范围内声明存在却未返回的子级。汇总 ID 不是稳定科目标识，仍不输出。结构一致不等于接口完整，不能据此排除同级科目或其他根科目被遗漏。

聚焦测试覆盖限制、错误及分组金额、重复科目、账套授权、网络错误及密钥拒绝。Web 组装场景覆盖发布的 Finance 预设、持久化结果、卡片和导出。账套 35601 的已授权期初样例为 110101 借方 1000、3001 贷方 1000，借贷平衡；一月、八月及九月父级查询与界面一致。实际九月工作簿保留四条科目、三条汇总及所有金额列。独立公开查询通过父级 ID 取得子科目 110101，默认查询只返回父级。以上核验仅覆盖这些样例，不证明层级完整获取、币种语义或整体财务报表验收。测试造数留在产品之外。
