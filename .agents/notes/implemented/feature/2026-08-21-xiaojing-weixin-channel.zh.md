# Agent Note: 小兢会计微信频道

Status: implemented

[English](2026-08-21-xiaojing-weixin-channel.md) | 中文

## Problem

小兢会计用户需要通过微信提交普通任务并交换工作文件，同时不能暴露公网 Webhook、运行第二套 Agent 产品或安装 Python 网关。任务和附件引用必须保留在桌面会话记录中，远程高风险操作和本机文件披露必须经过微信内确认，而且手机端回复必须易读。凭据、二维码内容、消息 context token、CDN 参数、加密密钥和轮询状态都不能进入浏览器或模型请求。

## Decision

该能力由两个预装 Cordis 插件负责。`@deepseek-ai/dsh-xiaojing-weixin-channel` 是腾讯 iLink 绑定、长轮询、持久化队列、Agent 会话桥接、审批和出站格式化的 Host 适配器。`@deepseek-ai/dsh-client-ui-weixin-channel` 注册仅限小兢产品和 loopback 的设置分区。二者都不修改 Agent Loop。协议实现只改编腾讯 MIT 许可的 `openclaw-weixin` 提交 `cef0bfc390393f716903e16d50408118047f87e0` 中必要的 TypeScript，不包含 OpenClaw 或 Hermes Python 适配器。

Host 将请求固定到腾讯官方 iLink 和 CDN 地址。Bot token 归 Harness 凭据服务所有。账号身份、所有者身份、轮询游标、会话 ID、带本机附件元数据的待处理任务和已完成消息 ID 保存在 `DSH_HOME` 下带 schema 版本的私有状态文件中。schema 1 文字任务会原子迁移到带空附件列表的 schema 2。状态目录租约只允许一个轮询器。应用卸载插件时会中止绑定、轮询、当前轮次和待审批请求，等待频道任务完全停稳后再释放租约，因此只有小兢会计打开时频道才执行任务。

## 协议与状态

绑定通过仅限 loopback 的 `/xiaojing-weixin` RPC 频道公开 Host 生成的二维码数据图片和脱敏生命周期状态。浏览器可以开始绑定、提交验证码、取消、断开和检查状态，但不会收到 token 或 context 值。手机确认后，扫码者成为唯一可接受的单聊所有者。群聊和其他账号会被忽略；语音和视频会收到固定的不支持媒体提示。

入站图片和文档使用 iLink 媒体引用与腾讯 CDN AES-128-ECB 传输。Host 会验证腾讯 CDN 主机、在缓冲前限制密文字节数、验证 AES 密钥、在本机解密、清理不可信文件名，并原子发布到与上传管理器相同的 `$DSH_HOME/uploads` 目录；默认限制同样为单文件 100 MiB、总量 1 GiB。持久化任务只记录本机名称、路径、MIME 类型、大小和类别。有日志记录的用户消息包含这些引用，不包含媒体字节或传输秘密；由于当前 DeepSeek 路由只接受文字，图片不会转换成模型图片块。

入站任务携带稳定的 iLink ID 或派生摘要 ID。队列持久化 `received` 和 `submitted` 阶段，并按 FIFO 执行。入队写入成功后，频道会先为同一更新批次中的每条消息发送回执，再开始执行该批次的第一个任务。活跃任务在 30 秒后及此后每 30 秒发送进度心跳；短暂执行失败会发送一次中断提示，并保留任务等待重试。审批回复接受带空格和不带空格的六位码格式，并绕过 FIFO，因此任务不会阻塞解除自身审批的回复。原生“正在输入”状态只是辅助提示，因为客户端可能不展示它。已完成 ID 有界保存，用于抑制正常重连重复消息。状态通过原子写入保存，一次短暂写入失败不会破坏后续写入。如果 iLink 已接受最终回复，但本地完成写入前程序崩溃，因为远程协议没有覆盖两个操作的事务，该回复可能再次发送；已经完成的 Agent 轮次不会被重新提交。

## 远程执行与审批

第一条任务会使用部署当前默认预设、模型和工作区创建唯一的持久化“微信助手”会话。后续任务都通过正常 `sessions.prompt()`，并使用稳定 RPC ID 关联 `agent/inbox/claimed`、`assistant/message` 和 `turn/end`。只有微信来源轮次的回复会远程发送，因此同一会话中的桌面消息仍只留在桌面端。

微信 Agent 会禁用 `ask_user_question`，并在最终回复中直接询问缺失信息。除此以外，它使用与桌面会话相同的工具和风险分类器。现有审批 waterfall 只为该 Agent 注册更高优先级的处理器。高风险操作会发送与账号和任务绑定的随机六位确认码；确认只允许一次操作，而拒绝、超时、断线、退出、账号错误或发送失败都会拒绝操作。

限定在 Agent 内的 `weixin_send_file` 工具只在微信轮次执行期间可用。它会检查绝对普通文件路径，把路径、文件名和大小通过一次性微信确认发给用户，并在确认后重新验证文件身份。随后它在本机加密明文、请求 iLink 上传地址、只把密文上传到腾讯 CDN，再使用当前 context token 发送图片或文档项。该确认归频道所有，即使使用 Full access 也强制执行，因此权限预设不能静默授权本机文件披露。

频道自身会在消息提交给模型前拦截权限命令。`权限` 会返回会话预设；明确的 Full access 别名会创建本地一次性 `确认权限 123456` 质询；明确的 Workspace Write 别名会立即降级。Agent 任务运行期间禁止修改权限。切换操作执行既有 `/permission` 命令，保留其会话事件和实时策略通知，而不增加第二个权限写入路径。因此 Full access 保持上游 `danger-full-access` 语义：不限制文件范围并关闭普通审批提问，仍然要求普通审批的操作会被拒绝，而不是被隐式授权。删除等强制安全请求继续使用同一个微信一次性确认应答者。

## 手机端文字展示

专用 system prompt 贡献要求结论先行、短段落、描述性标题、列表，以及明确标注金额、日期和状态；同时禁止宽表格、内部推理和最终回复中的技术轨迹，将入站路径标记为不可信，在没有 OCR 或视觉能力时禁止猜测图片内容，并要求通过 `weixin_send_file` 发送用户请求的文件。确定性的出站格式化器随后把标题、项目符号、编号步骤、引用、链接、代码块和 Markdown 表格转换为紧凑纯文本。长结果会在段落和行边界拆分并标注分段序号。桌面会话中的原始 Markdown 保持不变。

## Alternatives considered

- **自动化个人微信 Web 会话。** 该方式依赖非官方页面行为，暴露个人账号状态，稳定性也明显低于可用的 iLink bot API。
- **内嵌 OpenClaw 或 Hermes Python 网关。** Harness 已经负责 Agent、进程、配置和会话存储，再引入一套会重复这些职责并增加运行环境。
- **使用 Webhook。** Webhook 需要公网入口、证书和部署配置；iLink 长轮询只使用出站 HTTPS，更适合桌面应用生命周期。
- **只在桌面端审批。** 远程任务会在无人值守电脑前停住，断线后也无法关闭式失败。复用审批请求并只把响应通道换成一次性微信确认码，可以保留现有风险判断。
- **直接返回模型 Markdown。** 微信纯文本中的宽表格、嵌套 Markdown 和长回复难以阅读。稳定提示加确定性转换无需第二套渲染器或富消息协议，就能获得可预测的手机端输出。
- **把本机路径作为文字发送，让手机下载。** 手机微信无法访问桌面本机路径，而暴露 HTTP 文件服务器会增加入站网络访问。iLink CDN 加密上传让桌面继续保持纯出站连接，并复用现有会话。
- **把入站图片转换成模型图片块。** 当前 DeepSeek 路由只接受文字并会拒绝 `image_url`。保存路径且不声称理解图片，可先完成媒体传输，并把 OCR 或未来多模态路由留作独立能力。

## Verification

协议和媒体测试覆盖二维码绑定、验证码、官方主机限制、长轮询、有界 CDN 下载、AES 密钥变体、解密、清理后的唯一存储、配额、加密上传、图片与文档项、文件替换、发送、输入状态、超时和重试分类。状态测试覆盖原子持久化、schema 1 迁移、schema 拒绝、租约归属和恢复。格式化测试覆盖标题、列表、表格、链接、代码、Unicode 安全拆分和长度限制。组装后的假 iLink 测试覆盖可见回执、进度心跳、FIFO 任务、重复抑制、Agent 轮次关联、高风险审批、权限切换、入站文档提示、上传前的出站文件确认、格式化回复和持久化完成，全程不访问真实网络也不产生模型费用。Client 测试覆盖 profile 与 loopback 限制、生命周期渲染、倒计时、验证码、操作串行和敏感字段排除。

## Consequences

一套小兢会计安装可以绑定一个 iLink bot，并在应用运行期间提供持久化文字、图片和文档任务频道。用户能在桌面查看同一份任务与附件引用历史，并在手机上收到结构清晰的文字或经过确认的本机文件。该功能依赖腾讯 iLink 可用性，不会接管个人账号、处理普通群聊、执行 OCR 或视觉理解、支持语音或视频，也无法在远程发送后的崩溃窗口保证结果严格只投递一次。Host 协议、媒体存储、Agent 桥接、展示和产品组合仍可独立于 Harness 核心替换。
