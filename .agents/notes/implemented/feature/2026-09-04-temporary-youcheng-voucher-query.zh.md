# Agent Note: 有成临时凭证查询

Status: implemented

[English](2026-09-04-temporary-youcheng-voucher-query.md) | 中文

## 问题

账套连接核验成功并不会让聊天获得可调用的业务操作。文件搜索工具无法读取实时凭证，也不应获取 Host 凭据。

## 决策

[Finance 领域](../../../../packages/xiaojing/xiaojing-finance-domain/README.zh.md)增加一个 Finance 预设消费者和有界只读凭证操作。会话确定客户，Host 解析当前保存的账套 ID 和凭据。V2 财务列表要求账套名称，因此每次查询先解析精确 ID，并拒绝授权列表中的重名账套。查询期间目录变更会丢弃响应。模型只提供月份及分页参数，通过标准已记录工具结果接收脱敏分录数据。

## 考虑过的替代方案

可选导出从第一页开始读取，拒绝总数变化、短页及重复凭证，只有唯一凭证数与接口总数一致后才发布。它保留凭证张数与分录行数的区别及请求筛选条件。工作簿打开时直接显示业务分录，将普通范围和限制说明放在最后，不把接口名或技术摘要作为表格内容。金额保持文本以保留精度，外部名称不会变成公式。不推断币种、不编造合计，也不宣称取得供应商原子快照。不接收模型编造的分录或目标路径。

**临时 shell 请求**会暴露凭据，并把账套选择交给模型。

**报销凭证接口**服务于另一种流程，省略状态筛选时可能改变导出状态。

**完整连接器框架**超出了本次临时验证的范围。

## 后果

此可移除工具验证聊天到账套的读取，不实现记账、审批、支付、多账套管理或自动工作流。分页结果明确总数和后续页；缺失或无效金额不会被编造。不限月份的读取不承诺按最新日期排序。供应商基于名称的选择方式要求授权账套名称唯一。

## 验证

聚焦测试覆盖账套解析、凭据排除、取消、月份校验、分页、结果上限、咨询拒绝和并发修改。真实组装 Web 场景通过 Finance 预设执行模型工具调用，并对已记录结果和浏览器卡片制作快照；只 mock 模型和供应商网络。真实账套冒烟验证与可重复的 fixture（测试前置数据）分开进行。
