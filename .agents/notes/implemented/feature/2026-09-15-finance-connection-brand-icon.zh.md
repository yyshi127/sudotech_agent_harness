# Agent Note: 财务连接品牌图标

Status: implemented

[English](2026-09-15-finance-connection-brand-icon.md) | 中文

## Problem

通用绿色成功点可以表示连接成功，但不能说明当前帐套绑定属于哪个财务系统。完整展示供应商文字 Logo 会挤占紧凑的 Workspace 行，而在共享 Workspace 浏览器中硬编码有成又会让产品中立界面依赖单一连接器。

## Decision

`WorkspaceCategoryBadge.brandIconSrc` 允许产品类别为成功标记提供静态品牌图片。共享行把图片裁切为左侧 16 px 正方形并用它替代成功状态点；核验中、失败和未核验状态继续使用产品中立标记及无障碍状态说明。

财务客户类别仅在有成连接核验成功后提供有成财务 Logo。原有连接操作仍位于客户名称和帐套名称之间，并保留横向绿色的成功样式。打包资源保留完整文字 Logo，界面只显示左侧方形品牌图标。

## Alternatives considered

**在共享 Workspace 行中硬编码有成。** 共享包不应解释财务连接器身份，因此未采用。

**显示完整文字 Logo。** 狭窄侧边栏无法在不挤占客户名称和帐套名称的情况下容纳供应商文字，因此未采用。

**用品牌图标替换所有状态标记。** 品牌图标不能表达核验中、失败或未核验状态，因此未采用。

## Consequences

有成连接行无需增加第二段文字即可标识当前财务系统。后续连接器可以通过同一可选字段提供自己的图片，不需要预先建设供应商注册表或未实现的连接器界面。产品构建必须包含被引用的图片，provider 仍负责提供有意义的无障碍状态说明。
