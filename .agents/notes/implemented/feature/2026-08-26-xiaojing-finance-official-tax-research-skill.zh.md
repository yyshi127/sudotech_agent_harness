# Agent Note: 小兢会计 Finance 官方财税来源研究 skill

Status: implemented

[English](2026-08-26-xiaojing-finance-official-tax-research-skill.md) | 中文

## 问题

在客户档案、业务系统连接器或本地法规库尚未建立时，Finance模式需要第一项真正实用的财务能力。中国税务答案会随适用地区、纳税人身份、交易事实和相关期间变化；仅在人格中要求“优先使用官方来源”，并没有定义如何补齐事实、区分法律效力、发现失效文件或呈现依据。建设爬虫或保存法规正文则会引入本里程碑无法承担的内容权利、新鲜度、迁移和运营义务。

## 决策

Finance 预设在自己的 `skills/` 目录内提供纯指令的 `china-tax-official-research` skill。现有 `@deepseek-ai/dsh-skill-filesystem` 配置行通过相对 `baseUrl` 的自定义根目录加载它，因此该 skill 会随预设用于源码运行、安装、目录迁移和用户预设复制。标准模式和官方 Harness profile 看不到这个产品根目录。

该 skill 复用现有 `web_search` 工具。形成依赖规则的结论前，它要求识别适用地区、地方口径、主体或纳税人类型、交易、会计框架、期间和答案对应日期等重要事实。来源优先级从国家法律法规数据库或中国政府网发布的法律和行政法规开始，其次为国家税务总局与财政部的正式文件、经核验的适用地方机关，最后才是只作为解释材料的官方解读。第三方页面可以帮助发现文件，但不能作为结论依据。

每项重要依据都要区分法律效力、时效状态和与问题的关联程度。回答会说明核验截止日期、假设、判断过程、操作处理和风险，并使用官方来源表列出发布机关、标题、文号、日期、状态和直达链接。缺少官方正文、现行效力或适用性证据时必须标记`待核验`；搜索摘要不能被表述为完整条文。该 skill 也不能声称外部申报或交易已经完成。

产品 manifest 会登记 skill 路径。产品层校验只允许 Finance 与标准模式在两处不同：人格，以及相对路径的自定义 skill 根目录。校验会读取登记的源文件并固定权威域名和`待核验`规则。该能力不保存法规正文或用户数据，也不创建 Host 或 Client 服务包。

## 验证

小兢 Web 真实组装测试会同时挂载标准和 Finance agents，证明两者工具 schema 相同、只有 Finance 能发现 `china-tax-official-research`，并通过面向模型的 `skill` 工具加载实际正文。产品层校验会解析两份组装，拒绝未登记的配置行或配置漂移、缺失的 manifest 项、位于产品预设以外的 skill，以及官方来源和`待核验`规则被删除。无密钥 ACP 快照会固定模型可见的 skill transcript。

## 评估过的替代方案

- **建设本地法规语料或 RAG 索引。** 否决，因为目前没有取得授权、可做版本管理的源数据集，也没有新鲜度运营机制。残缺语料会让过时覆盖看起来具有权威性。
- **启用通用 HTTP 抓取提供方。** 否决，因为私有网络 SSRF 防护仍未实现，随包 profile 有意不加载该提供方。仅搜索的核验路径具有更小的安全和维护成本；摘要不足时，skill 必须保持非确定性结论。
- **把完整流程写入 Finance 人格。** 否决，因为每次 Finance 请求都会承担提示词开销，后续 skills 也无法独立演进或移除。
- **创建空的 Finance 服务包。** 否决，因为该能力只是建立在现有 skill 和 Web 服务之上的指令，没有新的 Service Definition、提供方、持久化状态或 Client 消费方。

## 结果

Finance模式无需冒充本地知识库，就能以可重复的官方证据纪律回答现行中国税收政策问题。结果仍依赖 DeepSeek 实时 Web 搜索是否可用，以及搜索结果能否提供足够官方正文；证据被阻断、不完整或互相冲突时，系统会给出受限结论，而不是编造规则。

删除 manifest 项、skill 目录、自定义根和聚焦验证即可移除该 skill。未来的文档提取、确定性计算器、客户上下文、有成或 SDOO 操作以及合规发现仍是独立能力，不会堆入本 skill。
