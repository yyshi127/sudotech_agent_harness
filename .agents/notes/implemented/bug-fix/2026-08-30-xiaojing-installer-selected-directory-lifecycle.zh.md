# Agent Note: 小兢会计安装器的安装目录生命周期

Status: implemented

[English](2026-08-30-xiaojing-installer-selected-directory-lifecycle.md) | 中文

## Problem

小兢会计欢迎页在 electron-builder 强制执行当前用户安装模式之前收集自定义安装目录。欢迎页离开回调曾把规范化路径赋给 `$INSTDIR`，但后续 `setInstallModePerUser` 会再次将其替换为注册表中的安装目录或当前用户默认 Programs 目录，因此全新安装会忽略界面中显示给用户的路径。

当安装记录缺失时，这个执行顺序更容易产生误导：安装器会把未注册的旧程序目录视为全新安装，即使用户选择了原目录，目标路径仍会被重置为默认值。

## Decision

自定义欢迎页把规范化后的目标目录记录在独立 NSIS 变量 `xiaojingSelectedInstallDirectory` 中。安装文件页的预回调在安装模式初始化完成后执行，并在解压和写入注册表开始前把该值恢复到 `$INSTDIR`。

能够识别的覆盖升级继续从 electron-builder 固定 GUID 的安装记录中取得目标目录，并隐藏目录选择入口。安装记录缺失时仍按全新安装处理；用户可以明确选择现有目录，但安装器不会扫描任意磁盘寻找失去注册信息的程序目录。

桌面身份验证要求安装器保留所选目录变量、安装模式初始化后的恢复回调，以及保存欢迎页规范化路径的赋值。

## Alternatives considered

**使用 electron-builder 标准目录页。** 标准目录页位于安装模式初始化之后，但会替换已经确认的小兢会计两阶段安装界面。

**使用 NSIS `/D` 参数重新启动安装器。** 这种方案仅为传递当前进程中已经存在的路径增加了额外进程生命周期和参数转义处理。

**修改 electron-builder 的 NSIS 模板。** 缺陷只来自小兢会计自定义页面的执行顺序；修改包管理器依赖会扩大后续升级和验证范围。

## Consequences

全新安装会采用小兢会计界面中选择并规范化的目录，包括自定义磁盘。已注册的覆盖升级继续使用原记录目录，不提供迁移安装位置的入口。缺少固定 GUID 安装记录的孤立程序无法被自动发现，需要用户明确选择目录。
