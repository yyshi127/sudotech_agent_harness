# Agent Note: 小兢会计安装器升级预检

Status: implemented

[English](2026-08-30-xiaojing-installer-exact-process-detection.md) | 中文

## 问题

Windows 安装器替换应用文件时，驻留托盘的桌面端和随包 Host 可能仍在运行。继承的 NSIS 应用检查通过判断可执行文件路径是否以 `$INSTDIR` 开头来识别进程；该值缺失或过期时，无关进程可能被误判为小兢会计。

覆盖升级还有一种显示相同提示的故障。electron-builder 会重试已安装卸载器返回的任何非零结果，最终统一显示 `appCannotBeClosed`，即使失败与进程无关。小兢会计 0.2.2 的解包依赖中存在绝对路径超过旧式 Win32 文件路径 259 字符限制的文件。旧卸载器无法原子移动这些文件，因此在没有任何小兢会计进程时仍会失败。

## 决策

小兢会计安装器通过 `customCheckAppRunning` 替换继承的进程检查。它从固定的当前用户安装记录读取 `InstallLocation`，并把进程处理交给随包 PowerShell 辅助程序。辅助程序只接受末级目录名为 `xiaojing-agent-desktop` 的路径，拒绝包含重解析点的安装树，枚举 `Win32_Process.ExecutablePath`，并且只把规范化可执行文件路径位于该精确根目录内的进程认定为本次安装拥有的进程。

存在所属进程时，辅助程序先启动 `小兢会计.exe --xiaojing-shutdown-for-update`。当前桌面实例通过 Electron 单实例通道接收该参数并正常退出。无法识别该参数的旧版本使用限时的精确路径兜底，只终止仍位于同一安装根目录内的进程。安装器和辅助程序自身的进程 ID 会被排除。

安装根目录内没有运行中的可执行文件后，辅助程序只删除绝对路径超过 259 个字符的旧版程序文件，并且只移除继承卸载器无法枚举的过长程序目录。它使用 Windows 扩展路径，验证每个目标仍位于固定安装根目录内；仍有不安全路径时会在替换前失败。随后继续使用 electron-builder 标准卸载器移除其余旧应用、快捷方式和注册表记录，再安装新文件。

辅助程序从不访问 `%APPDATA%`、“文档”工作区、凭据、会话、Finance 数据或其他受保护用户数据。目录验证、进程关闭或长路径兼容清理失败时，安装会停止，不会继续替换准备不完整的应用。

## 考虑过的替代方案

**按进程名匹配 `小兢会计.exe`。** 这种方式会遗漏随包 Node Host，也可能影响使用相同可执行文件名的另一套安装或其他 Windows 用户。

**绕过已安装卸载器并删除完整安装树。** 这种方式会重复 electron-builder 的快捷方式和注册表生命周期，扩大删除范围，并且容易遗漏后续安装器变化。

**要求用户手动关闭应用。** 关闭主窗口只会把应用隐藏到托盘，而且在没有进程的长路径故障中无法解决问题。

## 后果

安装根目录内没有所属进程时，覆盖升级会继续执行，不受无关桌面程序、浏览器或开发进程影响。旧版过长程序文件不会再阻塞已安装卸载器，也不会再被误报为程序关闭失败。替换准备开始后仍禁止取消升级，避免通过安装器界面中断兼容清理和标准卸载、安装序列。

桌面身份验证固定自定义检查、注册表路径读取、精确路径辅助程序、升级退出参数和长路径清理。辅助程序测试覆盖空安装、无关进程、安装目录内运行时进程、过长旧版程序路径、正常程序文件保留，以及错误产品目录名拒绝行为。
