# Agent Note: 日记账回答的证据限制

Status: implemented

[English](2026-09-07-journal-answer-evidence.md) | 中文

## 问题

一次真实 Finance 回答将完整性未验证的日记账空页说成当天没有发生，为空币种编码补充 RMB，并将相邻余额相同说成独立核验。查询和已发布工作簿保留了原始缺失值，缺陷在解释层。

## 决策

日记账工具说明及进入日志的结果提示明确约束空页、币种和余额表述。财务投影、查询范围及工作簿数值保持不变。所属 [README](../../../../packages/xiaojing/xiaojing-finance-domain/README.zh.md) 定义可观察的限制。

## 考虑过的替代方案

**仅保留通用免责声明**不能约束正文中与之矛盾的绝对结论，真实失败已证明这一点。

**生成文本关键词拦截器**无法可靠区分违规断言、引用及否定，还会干扰自然语言回答，因此不添加。

## 影响

同一解释规则适用于往来：上一页总计不是初始余额，重新查询的导出不是此前快照。往来工具消费方要求模型保留这些标签、在后续导出中沿用方向和期间，由 Host 自动收集并核对全部分页，再使用返回的文件路径。组合场景检查这些指令进入模型请求，不把 mock 回答视为遵守指令的证明。

往来查询及分析指令还将余额时点和汇总来源的约束延伸至最终结论。本地币种分组不能为供应商汇总行补充缺失币种。一次真实复测改正了上一页标签，却仍将返回余额称为月末余额；该结果仍是整体回答验收失败，不能证明指令保证模型遵守。

聚焦投影测试保留非零余额标记及缺失金额、币种。真实 Finance 组合场景验证指令进入模型请求、日志结果及导出卡片；其中模型使用 mock，不能证明真实模型遵守指令。真实聊天另行验收。本变更不授予业务写入权限，也不证明日记账完整性。
