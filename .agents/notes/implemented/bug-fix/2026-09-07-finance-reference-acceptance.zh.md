# Agent Note: 财务基础资料验收修正

Status: implemented

[English](2026-09-07-finance-reference-acceptance.md) | 中文

## Problem

只读浏览器验收发现了无依据的科目方向解释，以及无法区分的同名客户选项。

## Decision

基础资料结果只携带自身查询类型的方向说明。科目说明禁止推断借贷映射，同时保留原值。客户选择器复用工作区连接元数据展示账套名称和 ID，不读取凭据或改变会话绑定。

## Alternatives considered

**共用方向说明**将出纳账户映射与未核验的科目原值放在一起，容易引发跨类型推断。按类型提供说明可避免这种歧义。

**新增账套选择存储**会重复已有工作区元数据。展示已有元数据即可保留按客户 ID 选择，无需新增持久化格式。

## Consequences

单元测试覆盖分类说明、同名客户、选中 ID 和缺少已核验名称。完整应用浏览器快照包含科目方向原值及写入日志结果的禁止推断说明。模型是否遵守仍需真实模型验收；提示词不是确定性强制措施。
